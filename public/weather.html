Weather App

About A modern Weather App built with HTML, CSS, and JavaScript using WeatherAPI. It provides real-time weather information, including temperature, humidity, wind speed, feels-like temperature, and weather conditions. The application features a responsive glassmorphism UI, dark/light theme toggle, and local storage support to save user preferences.

technologies used

  • HTML
  • CSS
  • JAVASCRIPT
  • WEATHERAPI

Features

  • ✔ Search weather by city
  • ✔ Real-time weather updates
  • ✔ Temperature & Feels Like
  • ✔ Humidity & Wind Speed
  • ✔ Dark / Light Mode
  • ✔ Responsive Design
  • ✔ Local Storage
